# Machine Learning & Deep Learning Tasks

Репозиторий содержит коллекцию практических задач и лабораторных работ в области машинного обучения (Machine Learning), глубокого обучения (Deep Learning), компьютерного зрения (Computer Vision) и информационного поиска (Information Retrieval).

Проект оформлен в виде Jupyter-ноутбуков и может служить портфолио, демонстрирующим навыки предобработки данных, построения архитектур нейросетей, их обучения и валидации.

---

## Содержимое репозитория

В репозитории представлены следующие задачи:

1.  **information_retrieval.ipynb**
    *   **Направление:** NLP / Информационный поиск.
    *   **Описание:** Реализация алгоритмов ранжирования текстовых документов по релевантности поисковому запросу. Включает классические методы и/или современные подходы на базе эмбеддингов и нейросетевых моделей для построения поисковых систем.
2.  **img_classification_cifar_10.ipynb**
    *   **Направление:** Computer Vision / Глубокое обучение.
    *   **Описание:** Классическая задача распознавания изображений на датасете CIFAR-10 (10 классов объектов: самолеты, машины, птицы и т.д.). Реализация сверточных нейронных сетей (CNN) с нуля или дообучение (Fine-Tuning) базовых архитектур.
3.  **img_classification_OpenScene-Classification.ipynb**
    *   **Направление:** Computer Vision / Transfer Learning.
    *   **Описание:** Классификация сцен и открытых пространств с использованием предобученных моделей (вероятно, от сообщества Hugging Face / prithivMLmods). Ноутбук демонстрирует навыки адаптации State-of-the-Art моделей под специфичные датасеты.
4.  **jpn_symbols_classifications_kuzushiji_49.ipynb**
    *   **Направление:** Computer Vision / Исторические данные.
    *   **Описание:** Классификация японских рукописных символов на датасете Kuzushiji-49. Это усложненная альтернатива MNIST, требующая качественной настройки аугментации данных и архитектуры сети из-за специфики и схожести иероглифов.

---

## Технологический стек

В зависимости от ноутбука, в проектах используются следующие библиотеки и инструменты:
*   **Deep Learning frameworks:** PyTorch / TensorFlow
*   **Computer Vision:** OpenCV, torchvision
*   **NLP & Transformers:** Hugging Face (transformers, datasets)
*   **Data Science core:** NumPy, Pandas, Scikit-learn
*   **Visualization:** Matplotlib, Seaborn

---



## Чему я научился в этих проектах

*   Работа со сложными и нестандартными датасетами (Kuzushiji-49, кастомные классификаторы сцен).
*   Применение концепции **Transfer Learning** и использование предобученных SOTA-моделей из репозитория Hugging Face.
*   Реализация пайплайнов для обработки текстовых данных и построения матриц релевантности (Ранжирование/Text Ranking).
*   Оптимизация гиперпараметров нейросетей, борьба с переобучением (Overfitting) с помощью дропаутов, регуляризации и аугментации данных.
